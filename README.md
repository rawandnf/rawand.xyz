## Instagram links page

The quick links page is `links.html` and can be shared as `https://rawand.xyz/links`.
To add a link mentioned in a video, copy the example card in the comment near the top of
the first `.link-list` in `links.html`. Replace its URL, icon, title, and description,
then place it above the permanent Spotify and YouTube links.

The page currently uses the dark-shirt portrait from the local branding references as
its avatar. Replace `assets/img/links-profile.jpeg` if a different portrait is chosen.
